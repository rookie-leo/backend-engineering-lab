# Backend Engineering Lab

Laboratório de engenharia backend baseado em cenários reproduzíveis de falhas e problemas encontrados em sistemas distribuídos.

O objetivo não é construir um produto completo, mas investigar problemas isolados, reproduzi-los e comparar estratégias de solução através de código, testes e medições.
